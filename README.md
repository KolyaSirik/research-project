# Research Project

## Опис

Це тестовий репозиторій для практичного заняття з хмарних технологій (ПЗ 6).
Тема дослідження: трансформація інструментарію управління мікропідприємствами в умовах впровадження штучного інтелекту.

## Автори

- Сірик Микола Іванович (аспірант гр. PhD-D3-26, СНУ ім. В. Даля)

## Як відтворити аналіз

1. Встановити R (4.x).
2. Відкрити папку репозиторію і запустити: `Rscript analysis.R`
3. Скрипт читає `dataset.csv`, виводить описову статистику, тест Шапіро-Уілка, t-тест Уелча і тест Манна-Уітні, а графіки зберігає у файли `r_*.png`.

`dataset.csv` - навчальний згенерований набір (100 мікропідприємств: група control/experimental, бал, вік і стать керівника), реальних даних тут немає.
